# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct, by reference and without amendment. Read it there; it is not restated here, so there is one wording and it cannot drift.

## Scope

It applies in every space this repository runs: issues, pull requests, discussions, review comments, and any channel that speaks for the project. It applies to the maintainer as much as to anyone else.

## Reporting

Report a conduct problem privately to the maintainer, [@RizwanZafaris](https://github.com/RizwanZafaris), at [OPEN: a private address for conduct reports, owned by the maintainer]. Until that address is filled in, use the contact listed on the maintainer's GitHub profile. Do not report it in a public issue.

A report is read by the maintainer only, answered within seven days, and kept confidential. The enforcement ladder is the one in the Covenant's Enforcement Guidelines: correction, warning, temporary ban, permanent ban.

## Why a document system has one

The rules in this repository are argued, not decreed: [docs/PHILOSOPHY.md](docs/PHILOSOPHY.md) states each belief with the strongest case against it, and [CONTRIBUTING.md](CONTRIBUTING.md) says the pull requests that land are the ones that beat a counter-argument. That only works when disagreement is with an argument, never with a person.
